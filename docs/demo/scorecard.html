How these are measured

Deployment frequency
Successful runs of the deploy workflow on the default branch.
Lead time for changes
Median time from a commit landing on the default branch to the first successful deployment that includes it.
Change failure rate
Failed deployments, plus successful ones followed within 24 hours by an issue labelled incident, divided by all deployments.
Recovery time
Median time from a failed deployment to the next successful one, and from an incident being opened to being closed.
